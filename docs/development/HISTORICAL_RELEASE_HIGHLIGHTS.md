# Historical release highlights

These short summaries fill gaps where the published release and tagged README
did not contain a version-specific `What's new` list. They are based on the
tagged source, release comparison, and linked release PR when available.

### What's new in v5.2.2

- **Desktop reliability:** reviewed shutdown, updater, title-bar, tray, and exact Git status fixes were included in this patch release, with regression coverage and synchronized version metadata. See [release PR #92](https://github.com/engasnm111/lnwjud/pull/92).

### What's new in v4.6.1

- **Desktop controls and updates:** added scheduled update checks, tray and title-bar behavior, and clearer version/update UI while refining the Desktop MCP capability contract. These changes shipped in the [v4.6.1 release commit](https://github.com/engasnm111/lnwjud/commit/c83951a8e2720d31addab996c3400a6070ce669b).

### What's new in v4.0.0

- **Expanded local gateway:** added scoped WSL execution, annotated Set-of-Marks capture, trace-linked health and audit data, semantic tool routing, a Windows OCR helper boundary, and a branded tray. The [tagged README](https://github.com/engasnm111/lnwjud/blob/v4.0.0/README.md) records the compatibility and security boundaries.
- **Workflow and context tools:** compound/parallel workflows, persistent indexing, and Context Economy were included in the v4 gateway.

### What's new in v3.0.2

- **Desktop layout fix:** repaired card-border overflow and centralized version configuration, as recorded in the [release commit](https://github.com/engasnm111/lnwjud/commit/5f58b5237a7f8bde7a6fdf91cf7c736357a349f7).

### What's new in v3.0.1

- **Responsive Desktop:** expanded the main layout to use the available height and integrated Git status into the Git page. See the [v3.0.1 tag](https://github.com/engasnm111/lnwjud/releases/tag/v3.0.1).

### What's new in v3.0.0

- **Windows Desktop gateway:** shipped the branded tray, permission enforcement for Desktop MCP capability tools, profile-safe stdio/Tunnel startup, and stable external Tunnel status. The [tagged README](https://github.com/engasnm111/lnwjud/blob/v3.0.0/README.md) also documents the 184-tool compatibility baseline and Context Economy.

### What's new in v2.2.2

- **Context-aware discovery:** the tagged runtime includes Context Economy for quota-aware discovery and duplicate-aware delivery. See the [tagged README](https://github.com/engasnm111/lnwjud/blob/v2.2.2/README.md) for its visibility and access boundaries.

### What's new in v2.1.0

- **Desktop and Tunnel operation:** added a branded Windows tray, Desktop capability permission enforcement, profile-safe stdio/Tunnel startup, and stable external Tunnel detection. See the [tagged README](https://github.com/engasnm111/lnwjud/blob/v2.1.0/README.md).

### What's new in v1.0.0

- **Initial public release:** introduced the Windows-local Desktop and MCP gateway. Later release notes describe changes relative to this first version.

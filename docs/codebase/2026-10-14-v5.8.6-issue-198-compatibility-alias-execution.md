## Outcome

The local MCP server already advertises and validates `engineeringGateUpdates` and `engineeringReviewFindings` on `checkpoint_goal`. Issue #198 independently reports that the ChatGPT-facing `mcp__lnwjud_CF` declaration is missing those properties before a request reaches the server. The direct Cloudflare connector is unavailable in this session, so its imported declaration and cache cannot be inspected.

For v5.8.6, the registry now publishes `checkpoint_goal_engineering` as a compatibility name. It reuses the exact strict checkpoint schema and the same authenticated Goal handler, including existing lease, revision, authorization, and receipt checks. The alias follows `checkpoint_goal` availability, so a disabled canonical operation cannot be reached through the alias. The original `checkpoint_goal` name and behavior remain intact.

Issue #194 was resolved in v5.8.5: read-only audits no longer imply deployment authorization, and active Goals can reconcile corrected classification while preserving required-gate enforcement. It is included here as regression coverage, not as a new v5.8.6 code change.
